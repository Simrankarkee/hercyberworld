This week's challenge practises the encodings from the lesson **Hashing vs Encryption vs Encoding**.

Decode this message. It has been encoded **twice**:

```
NjM3OTYyNjU3MjVmNjk3MzVmNjY3NTZl
```

**Hints**

1. The outer layer ends up as letters and numbers only
2. After the first decode you'll see only the characters 0–9 and a–f

Reply with the **steps and tools** you used. CyberChef, the command line and Python are all welcome. Please hide the final answer so others can try first.
